- **Sign, measured by the Planner before this file (numbers only, `[private path]`):**
  - On a 1024 × 1024 box inside W, organizer w00 SV layer k matches our TOL-20 render's layer 108 − k (anti-diagonal mean
    r 0.917, diagonal 0.047, slope −1.0; `planner_sign_org2.json`). Our render's raw +o is outward
    (`checks/[internal item]/planner_sign.json`), so **on the organizers' SVs raw +o = inward**.
  - s022814's grid normals agree with w00's at the nearest vertex on 99.8 % of the window (median dot 0.98), and s022814
    sits on w00's +n side on 100 % (`planner_normals.json`): same renderer, same orientation, same sign.

  - Hence: **in24 = a* + 10 layers (+24.0 µm inward), out24 = a* − 10 layers (24.0 µm outward)**; edge arms in48 = a* + 20,

## Outcomes (per rater; frozen; `fw.py rater` / `combine`, self-tested)

- **Valid rater:** every picture answered, `f_05` called rows, ≤ 1 of the surface blanks (ctrl, in24, out24, H9, 10 mm) called
  rows, and ≥ 1 guard on the page. `f_06` reported only. Else VOID. A level counts only if its own blank is not rows.
- **Window:** ctrl blank rows → VOID (control). **WINDOW-YES** = ctrl rows; **WINDOW-NO** = ctrl not rows ("the organizers'
  s022814 surface does not show its labelled text on this chain", like s214732 for agents, B2).
- **Depth (WINDOW-YES):** an arm whose blank is rows is uncountable → INCOMPLETE. Else **WIDE-HOLDS** = in24 and out24 rows;
  **NARROW-OUT** = in24 rows, out24 not; **NARROW-IN** = out24 rows, in24 not; **NARROW-BOTH** = neither.
- **Guard:** the rater is **lenient** if more than half of their guard pictures are called rows (Sebastien: 1 of 1; Chris: 2 or
  3 of 3). A lenient rater's WIDE-HOLDS becomes **ALL-ROWS** (a lower bound only). A lenient rater's NARROW-* stands ("not rows"
  is robust).
- **Reader (WINDOW-YES):** H9-ROWS / H9-NO-ROWS; UNCOUNTABLE if its blank is rows; "H9 DROPPED" if Stage 0 dropped it.
- **1 cm² (WINDOW-YES; rated after the same text at 20 mm, so primed; descriptive):** 1CM-READS-PRIMED = both 10 mm windows rows;
  20MM-NEEDED = fewer; UNCOUNTABLE if the 10 mm blank is rows.
- **Edge ±48 µm:** descriptive calls only.

**Item verdict (two raters):**
- **CONFIRMED** = WIDE-HOLDS from two valid raters (neither lenient). The working assumption is confirmed on text neither
  human had seen; Sebastien rewords the `config.json` objective (BOARD decision 11).
- **NARROWED: NARROW-X** = the same NARROW label from two valid raters. The working assumption is narrowed ("on a weaker
  surface"); BRIEF's depth line prints the narrower band per side.
- **WINDOW-NO** = both valid raters WINDOW-NO. The assumption stays unconfirmed (W only); package (b) says every read is from W.
- **ONE RATER / SPLIT / ALL-ROWS / INCOMPLETE** = reported per rater, no rewording; the assumption stays a working assumption.
- **VOID** = no valid rater. Reported; nothing changes.
- **Kill date: Oct 13.** If Chris has not rated by then, the Runner scores with `--final` (one rater, no rewording).

**Perfect performer:** inward and outward as readable as the ctrl (~0.9 per look) gives WIDE-HOLDS per rater ~0.81 and two-rater
